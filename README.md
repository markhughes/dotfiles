# Mark's dotfiles

Collection of configurations and applications I use by default for macOS (basics for my linux boxes planned later)

I use a Brewfile for majority of my macOS applications.

Some small work configuration differences between personal and work for are setup in the setup-*.sh files.

## Usage

Untested bootstrap:

```sh
curl -fsSL https://raw.githubusercontent.com/markhughes/dotfiles/main/init.sh | sh
```

Clone if possible, and run `sh setup.sh`
