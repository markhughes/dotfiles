## Preferences

- Ask before committing to git, human review is preferred first. 
- Prefer concise, direct answers. Skip preamble.
- Use Australian English
- Do not include unnecessary comments or docstrings
- When something goes wrong, stop and re-plan. Don't keep pushing
- A notion tool is available, confirm before editing. 
- When asked to to document notes in Notion, ask for a file, or suggest putting it in a page under Claude Notes in Notion https://app.notion.com/p/Claude-Notes-39e8183ab6f680a49f30e75331fee60f

## Conventions

- Match the style, naming, and structure of the surrounding code.
- Ask before doing anything hard to reverse (deletes, pushes, external calls).

## Tooling

- Shell: zsh. Editor: neovim for terminal, VS Code.
- Dotfiles and installed applications are managed with GNU stow and a setup.sh in ~/dotfiles
- gh command line available for working with GitHub
- git repos live in ~/src, seperate by <host>/<org or user>/<repo name> examples: ~/src/github.com/markhughes/dotfiles
